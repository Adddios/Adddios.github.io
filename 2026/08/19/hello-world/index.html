发表于2026-08-19|更新于2026-08-19|博客建站
|浏览量:

💡 小贴士： Hexo + Butterfly 极速速查手册，包含日常推送命令、图片插入技巧以及 Butterfly 特色排版标签。

🚀 一、 Hexo 日常三连击指令

1. 本地写作与预览

hexo new post "文章标题"   # 新建一篇文章
hexo clean && hexo s      # 清理缓存并启动本地预览 (http://localhost:4000)
2.一键发布推送至 GitHub
hexo clean && hexo g && hexo d

二、 图片插入规范（开启 Post Asset Folder 模式）
放在文章同名文件夹下的图片，在 Markdown 中使用 Hexo 官方标签引用，防止图裂：
{% asset_img 图片名.png "图片下方显示的描述文字" %}
